# Grenzen

Der ReiterStudio Resonanzrahmen hat klare Grenzen:

- Er erkennt keine Autoren  
- Er erkennt keine KI  
- Er bewertet keine Wahrheit  
- Er interpretiert keine Menschen  

Er macht ausschließlich sichtbar:

- was im Text vorhanden ist  
- was fehlt  
- was dadurch sichtbar wird  

Die Ergebnisse sind keine Aussagen über eine Person,
sondern ausschließlich Beobachtungen der Textstruktur.
